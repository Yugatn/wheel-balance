# Wheel of Balance / Колесо баланса

Самостоятельный веб-прототип **колеса баланса** для структурированной самооценки жизненных сфер. Инструмент помогает замечать изменения и формулировать направления развития; его результаты **не являются медицинским диагнозом или профессиональной психологической оценкой**.

## Что находится в репозитории

- `index.html` — основной веб-интерфейс.
- `two-wheels.html` — отдельный интерфейс с двумя колёсами.
- `adaptive-wheel/` — материалы адаптивного колеса.
- `AI_CONTEXT.md` — границы проекта и правила работы с пользовательскими данными.
- `SECURITY.md` — сведения по безопасности.

## Принципы

Самоописание не равно личности; один показатель не должен определять человека целиком. Данные и интерпретации необходимо разделять, а сбор и хранение сведений — объяснять пользователю.
