# Контекст проекта

Wheel of Balance — самостоятельное приложение для структурированного самоописания баланса сфер жизни.

## Связь с экосистемой

Канонический источник:
https://github.com/Yugatn/ambivalent-solipsism

Основной связанный проект:
https://github.com/Yugatn/psy-tools

## Правила

- Результат является снимком самооценки, а не диагнозом.
- Один показатель не должен определять человека целиком.
- Изменения интерфейса не должны превращать инструмент в систему скрытого убеждения.
- Пользователь должен понимать, какие данные собираются и зачем.
- Экспорт и хранение данных должны быть минимальными и прозрачными.
- При добавлении интерпретаций отделять вычисление от авторского объяснения.

## Архитектурная роль

Репозиторий отвечает за приложение Wheel of Balance. Общие философские определения не копируются сюда целиком.
